Canyon Chase — a 3D chase-view flight game: thread the glowing rings of a red-rock desert canyon, dodge rock pillars and arches, go faster with every ring. Three lives, near-miss bonuses, and a HUD with altitude, speed and heading.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Fly with arrow keys / WASD, Shift to boost, Space to brake, drag the mouse to steer.
